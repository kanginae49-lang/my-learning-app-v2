# 우리집 학습관리

## GitHub Pages 배포
1. 압축을 풀어 안의 파일 5개를 저장소 `my-learning-app-v2` 최상위에 업로드합니다.
2. `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon.svg`, `README.md`가 같은 위치에 있어야 합니다.
3. GitHub 저장소 Settings → Pages → Deploy from a branch → main / root로 설정합니다.
4. 배포 주소: https://kanginae49-lang.github.io/my-learning-app-v2/

## 데이터 안내
기록은 브라우저 localStorage에 저장됩니다. 정기적으로 설정·백업에서 JSON 백업을 다운로드하세요. 다른 기기에서 복원할 수 있습니다.
